# Changelog

## 1.0 (2026-11-08)

First public release.

- Win32 runtime for Civilization II MGE on PS Vita (winx86 / Box86 dynarec, kubridge)
- Static recompiler and Windows patcher for a fully native build from your own `civ2.exe`
- Controller, touch and on-screen keyboard support; quick-command menu; English and German UI
- CD music from audio files, including in-game music selection
- Correct dialog rendering (radio buttons), memory-leak fixes, double-buffered audio
- timerdll.dll re-implemented natively
- Public VPK shows an emulation-mode notice; patcher checks Smart App Control
