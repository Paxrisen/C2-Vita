C2-Vita 1.0 - PS Vita Laufzeitumgebung / runtime
=================================================

DEUTSCH
C2-Vita ist eine inoffizielle Laufzeitumgebung fuer die PS Vita. Es enthaelt
KEINE Spieldateien und keinen Programmcode des Originalspiels.
Benoetigt wird eine eigene, legal erworbene PC-Version von
Civilization II Multiplayer Gold Edition (5.4.0f).
Installation: den kompletten Spielordner nach ux0:data/civ2/ kopieren.
Optional: CD-Musik als ux0:data/civ2/MUSIC/Track02.ogg ... (ogg/mp3/wav).
Benoetigte Plugins: kubridge. Empfohlen: vita-turbo-storage.
Bedienung: Start+Select = Einstellungen, Select = Schnellbefehle (Standard).
Kein offizielles Produkt; nicht verbunden mit den Rechteinhabern.
"Civilization" ist eine Marke ihrer jeweiligen Inhaber.

ENGLISH
C2-Vita is an unofficial PS Vita runtime. It contains NO game files and
no program code of the original game. You need your own legally obtained
PC copy of Civilization II Multiplayer Gold Edition (5.4.0f).
Install: copy the whole game folder to ux0:data/civ2/.
Optional: CD music as ux0:data/civ2/MUSIC/Track02.ogg ... (ogg/mp3/wav).
Required plugin: kubridge. Recommended: vita-turbo-storage.
Controls: Start+Select = settings, Select = quick commands (default).
Not an official product; not affiliated with the rights holders.
